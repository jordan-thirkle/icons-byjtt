Interface Action Icons

Common actions should be instantly recognisable and consistent across your product.

14 curated concepts · open source

Why this collection exists

Open-source action icons for creating, editing, confirming, deleting, downloading, uploading and managing interface state.

Practical guidance

  • Prefer a familiar action glyph over a decorative metaphor.
  • Use destructive icons with explicit surrounding labels or confirmation UI.
  • Keep icon-only controls large enough to operate comfortably.

Which icons belong in interface action icons?

Open-source action icons for creating, editing, confirming, deleting, downloading, uploading and managing interface state.

How should these icons be used?

Treat the icon as a semantic visual aid, preserve an accessible name for meaningful controls, and keep the surrounding interaction explicit.
