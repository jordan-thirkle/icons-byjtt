# @byjtt/icons-svelte

Svelte-friendly access to the canonical JTT Icons catalogue.

```bash
npm install @byjtt/icons-svelte @byjtt/icons
```

Use the `JttIcon` helper with the canonical icon name. The package keeps icon identity in the shared JTT core catalogue instead of creating a second naming system.

See https://icons.byjtt.com/docs/ for the full integration guide.
