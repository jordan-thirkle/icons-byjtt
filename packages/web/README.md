# @byjtt/icons-web

A dependency-light Web Component for JTT Icons.

```bash
npm install @byjtt/icons-web
```

```html
<script type="module">
  import "@byjtt/icons-web";
</script>

<jtt-icon name="search" title="Search" size="24"></jtt-icon>
```

The element resolves names against the canonical JTT Icons package and exposes size, color, stroke-width and title attributes.
