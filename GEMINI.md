# JTT Icons — Gemini Guidance

`AGENTS.md` is the primary repository contract.

Preserve canonical icon names, semantic metadata, SVG geometry, accessibility and public URL contracts.

Before changing a concept, search existing icons and relationships. Change source-of-truth files before generated output.

Before completion run `npm test`, `npm run check`, regenerate outputs and inspect the diff.

Treat the repository as public. Never commit secrets, credentials, private data, local machine paths or internal-only files.
