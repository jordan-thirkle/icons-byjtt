AI-native icon infrastructure

Give your agent the right icon.

JTT Icons exposes one canonical icon vocabulary across humans, code, agents and design workflows. Search by meaning, retrieve exact SVGs, and keep icon choices deterministic.

Agent interfaces

What an agent can do

  • Search by natural-language intent, aliases, context and semantic relationships.
  • Retrieve canonical metadata and raw SVG without guessing identifiers.
  • Recommend a small, coherent shortlist for a UI requirement.
  • Preserve accessibility and the JTT line-family rendering contract.
  • Choose raw SVG, React, Vue, Svelte, Web Component or CDN output for the user's stack.

Designed for the AI age

AI assistants increasingly choose implementation details on behalf of developers. JTT therefore treats naming, semantics, provenance, accessibility and deterministic retrieval as first-class parts of the icon system.
