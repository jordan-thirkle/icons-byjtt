One vocabulary. Many ways to use it.

Designed for humans. Structured for machines.

Use JTT the simple way: find an icon, copy the SVG and ship. If you use React, Vue, Svelte or Web Components, install the package. If you use AI, the same names, semantics and relationships are available to the tools helping you build.

No design-system expertise required. No special workflow required. Start with the icon you need and grow from there.
