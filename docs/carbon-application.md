# Carbon Ads application brief

JTT Icons is an open-source icon system for developers and designers.

## Site

- Primary site: https://icons.byjtt.com
- Repository: https://github.com/jordan-thirkle/icons-byjtt
- Catalogue: 300 canonical concepts
- Audience: developers, designers, frontend engineers and AI-assisted builders
- Monetization placement: one restrained Carbon placement outside the primary icon interaction path

## Product fit

JTT Icons is specifically aligned with Carbon's developer/designer audience. The product provides searchable SVG assets, implementation documentation, framework packages, semantic discovery and AI-agent tooling.

## Technical readiness

- Provider-neutral Carbon configuration exists in metadata/monetization.json.
- Carbon is disabled until approval and a zone key are supplied.
- The generated site has a dedicated ad hook and placement styling.
- No competing ad network is planned on Carbon-enabled pages.

## Information still required from the publisher account

Carbon's current publisher application asks for the site URL and traffic statistics. Add current monthly page views and audience information from analytics before submission.

## Submission

Carbon currently accepts publisher applications through its publisher join page. Approval is invitation-based and Carbon states that it evaluates audience relevance, monthly page views, active maintenance, network capacity and compliance with its placement/exclusivity rules.

Do not enable the ad until Carbon has approved the site and supplied the official dashboard code or zone key.
