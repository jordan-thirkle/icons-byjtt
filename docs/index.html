JTT Icons documentation

Ship with JTT Icons.

Everything you need to find an icon, copy it into an interface, or consume the generated package.

1. Find

Use the library search by name, alias, meaning, context or category. Search is enhanced in the browser while the catalogue remains statically crawlable.

2. Use the SVG

<img src="https://icons.byjtt.com/icons/search.svg" alt="Search">

3. Install the package

npm install @byjtt/icons

The package is generated from the canonical catalogue and exposes individual icon modules plus the full icon map.

4. Accessibility

Each icon carries an accessibility classification in canonical metadata. Decorative icons should be hidden from assistive technology; meaningful icons should receive an appropriate accessible name; interactive controls should use the surrounding control label rather than relying on the glyph alone.

5. AI discovery

Agents can use llms.txt, llms-full.txt and the stable catalogue. Match requests against canonical names, aliases, tags and contexts rather than inventing identifiers.
